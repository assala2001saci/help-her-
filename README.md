# HELP HER

## About the Project

HELP HER is an early-stage digital mentoring platform designed to help women and girls build confidence in technology by connecting learners with mentors.

The project supports SDG 5: Gender Equality.

## Features

- Digital skills and learning resources
- Beginner-friendly AI and online safety content
- Mentor profiles and areas of expertise
- A prototype mentor-matching feature
- An AI assistant powered by the Google Gemini API

Some features are still under development.

## Technologies

- HTML, CSS, and JavaScript
- Node.js and Express
- Google Gemini API

## Project Structure

- `index.html` — Main website page
- CSS and JavaScript files — Frontend styling and interactions
- `server/` — Backend application and server-side tools

## Run Locally

1. Install Node.js and npm.
2. Clone or download this repository.
3. Open a terminal in the `server` directory.
4. Run `npm install`.
5. Configure the required environment variables in a local `.env` file. Follow the variable names expected by the application.
6. Run the backend using the start command defined in `server/package.json`.
7. Open the frontend using a local development server if required.

Never commit `.env` files or API keys.
